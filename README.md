# air_transportation_network
Graph-theoretic analysis of the global air transportation network (3,214 airports, 66,771 flight records). The network is a hub-dominated small world (σ ≈ 2.67): 99.19% of airports form one giant component, the top 10% hold 84.5% of edges, and hub importance is multi-dimensional. Louvain communities mirror geography and national borders.
