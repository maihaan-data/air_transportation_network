# Global Air Transportation Network Analysis
This study applies graph-theoretic methods to analyse the global air transportation network comprising 3,214 airports and 66,771 scheduled flight records. The main aims are to characterise the network's topological structure, identify its most important airports, and examine whether well-known theoretical properties of complex networks, such as heavy-tailed connectivity, small-world behaviour, and geographically structured community organisation, are present in this real-world system. To address these aims, three complementary graph representations (a directed multigraph, a simplified directed graph, and an undirected weighted graph) were built and analysed using standard network-science tools (e.g., python-igraph, NetworkX), combining global and node-level descriptive statistics, centrality measures, maximum-likelihood distribution fitting, degree- and attribute-based assortativity analysis supported by bootstrap confidence intervals and a degree-preserving rewiring null model, random-graph null-model comparisons, and community detection with algorithm stability testing. The analysis first reveals that, despite spanning across 3,214 airports worldwide, the network is highly connected, with 99.19% of airports belonging to a single giant component and an average shortest path length of only 3.96 hops. At the same time, this connectivity is highly concentrated, with the top 10% of airports by degree accounting for 84.5% of all edges, and both the degree and strength distributions are heavy-tailed, although likelihood-ratio tests show that a pure power law is significantly outperformed by the truncated power law, lognormal, and stretched-exponential alternatives. However, centrality results show that hub importance is not only about degree and connectivity, but rather a multi-dimensional property: some airports are important because of traffic volume (Atlanta), others because they are efficiently positioned relative to the rest of the network (Frankfurt, Paris, Amsterdam), and others because they serve as strategic bridges disproportionate to their size (Anchorage, Dubai). The network also exhibits genuine small-world behaviour, combining high clustering with short average path lengths, a pattern that survives comparison against random-graph null models controlling for both edge density and the empirical degree sequence (σ ≈ 2.67). Finally, examining the network's mesoscopic structure shows that communities identified via the Louvain algorithm align closely with real-world continents. Assortativity analysis shows that the near-zero degree assortativity (-0.017) conceals opposing tendencies at different degree scales: a low-degree dip and a mid-degree rise in average neighbour degree are genuine mixing patterns, whereas the decline at the highest degrees is largely a structural consequence of the degree sequence. Meanwhile, strong country and time-zone assortativity indicate that national borders and geographic proximity are the most straightforward elements organising how the network is wired, while connectivity-based preferences still play a real but scale-dependent role. Taken together, these findings depict the global air transportation network as a geographically organised, small-world, hub-dominated system that is heavy-tailed but not a pure power-law network.

The dataset used in this project represents a network of regularly scheduled flights among airports worldwide. The original data were obtained from the OpenFlights dataset ([openflights.org](https://openflights.org/)), and subsequently processed into a format suitable for network analysis. The processed dataset is available through the Netzschleuder network catalogue ([Netzschleuder: the network catalogue, repository and centrifuge](https://networks.skewed.de/net/openflights)). 

The dataset consists of two tables: 
- nodes.csv lists 3,214 airports with identifying attributes (name, city, country, IATA/FAA and ICAO codes), geographic coordinates (latitude, longitude, altitude) and time zone information (UTC offset, daylight-saving-time rule) 
- edges.csv lists 66,771 flight records, one row per regularly occurring commercial flight by a particular airline from an airport to another, with source/target airport indices, great-circle distance, operating airline (name and code), a codeshare flag, aircraft equipment, and number of stops. It was noted in the source that multiple edges can exist between the same pair of airports when several airlines operate the route or when a single airline operates multiple flights on the same route each day.
